## 📖 About

**For Adelia | My Valentine** is a modern, romantic digital love letter web experience designed to express deep devotion, cherished memories, and celebrate Valentine's Day.

Styled with modern **Tailwind CSS**, glassmorphism cards, fluid liquid glass shaders (`FxFilter`), and floating particle animations, it presents an unforgettable personalized digital experience complete with interactive love quizzes, photo memories, and celebratory confetti showers.

---

## ✨ Features

- 💎 **Liquid Glass Aesthetics**: Modern frosted-glass and glassmorphism styling with soft romantic gradients.
- 🎉 **Interactive Confetti Celebrations**: Full-screen confetti explosions powered by `canvas-confetti` on interactive actions.
- 📜 **Personal Love Letter & Timeline**: Eloquently formatted letter, shared milestones, and romantic reflections.
- 🌸 **Fluid Ambient Animations**: Custom CSS keyframes for floating hearts, pulsing glow effects, and smooth scroll transitions.
- 🎵 **Integrated Music Atmosphere**: Embedded romantic soundtrack with intuitive player controls.
- 📱 **Mobile & Desktop Responsive**: Seamlessly optimized for iPhone, Android, tablets, and widescreen displays.

---

## 🛠️ Tech Stack

- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom Valentine color palette (`#fff1f2` to `#881337`)
- **Visual FX**: [Canvas Confetti](https://github.com/catdad/canvas-confetti), [Aura FxFilter](https://www.aura.build/)
- **Icons**: [Iconify](https://iconify.design/)
- **Typography**: [Google Fonts](https://fonts.google.com/) (Plus Jakarta Sans, Playfair Display)

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kecrwn/ValentineDayMyLove.git
   cd ValentineDayMyLove
   ```

2. **Open in browser:**
   Open `index.html` directly in any web browser, or serve locally:
   ```bash
   python3 -m http.server 8080
   ```

3. Navigate to `http://localhost:8080` to experience the website.
